Overview
A C++ implementation of the Capacitated Vehicle Routing Problem with Time Windows (CVRPTW). Features object‑oriented design, route optimization logic, constraint handling, and test scenarios demonstrating practical applications in logistics and scheduling.

Project Structure
src/ — solver implementation

tests/ — example scenarios

cvrptw.vcxproj — Visual Studio project

Build & Run
Open the .vcxproj in Visual Studio and build the solution.
